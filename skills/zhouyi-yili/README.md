# zhouyi-yili · 周易义理

[← 返回技能包首页](../../README.md) · [安装](../../README.md#安装)

> ### 用《周易》看**处境**，不是用它算**命**。
> 观象定卦 → 析爻（当位/得中/有应/承乘）→ 落到大象辞给的行动纲领。

一句话：不用生辰、不排大运、**不断吉凶**。它把六爻结构翻译成
「你处在什么位置、往哪个方向走更合宜、风险在哪」——**结构分析，不是预言**。

---

## 🎯 它是干什么的

| 步 | 做什么 | 依据 |
|---|---|---|
| 1 | **定卦**（先判该不该接；未指定卦名就用摇卦得到本卦与变爻） | 本卡只接「当下处境的结构与行动」这类问题 |
| 2 | **观象**：上下卦的卦德与取象 → 取大象辞的行动纲领 | 十翼·大象傳 |
| 3 | **析爻**：当位 / 得中 / 有应 / 承乘；有变爻则取之卦看趋势 | 十翼·彖傳 / 小象傳 |
| 4 | **深读**（按需三选一）：序卦相承 / 彖傳实例 / 文言逐爻 | 序卦傳 / 彖傳 / 文言傳 |
| 5 | 落到**五段产出**：处境性质／所处位置／行动方向／风险提示／**非预测声明** | — |

**谁适合用**：遇到两难、想换个结构视角的人；读《周易》原文想有人把术语讲清的人；
以及——**想看看"不算命"的《周易》长什么样**的人。

## 🔬 它凭什么可信

- **引擎 56 项 + 参考 41 项自检全绿**，且不是「没崩」式的断言：
  T5 用「既濟全当位、未濟全失位」钉死结构不变量，T8 钉死摇卦可复现，
  T13 钉死 `references/` 与引擎**同源**（参考文件不许与引擎算出来的不一致）。

```bash
python3 skills/zhouyi-yili/tests/test_engine.py   # 56 项
python3 skills/zhouyi-yili/tests/test_refs.py     # 41 项
```

- **语料 9 份 / 807 段 / 约 22,000 字**，十翼齐备（彖上下、象上下、繫辞上下、文言、说卦、序卦、杂卦），
  语法完整性由 `test_corpus.py` 守着：彖傳 64 段、小象傳 384 段（64×6）、大象傳 64 段。
- **引语逐条锚定**：卡里每条引语都带 `src-XX §N`，可用段号锚定核验复算（详见 [`VERIFY.md`](./VERIFY.md)）。
- **坦白一处**：`audit-coverage` 对本卡报「覆盖率 0%」是**不可直接采信的数字**——
  它按整段 3-gram 判定，而本卡只从每段摘一个短句。改用「是否含该段任一 ≥8 字逐字片段」重算得
  **18/807 段 = 2.2%**（本卡是**选择性引用**，不是全覆盖——`COVERAGE.md` 里如实写了）。

## 🚧 它拒答的事（这是设计，不是缺陷）

这张卡有一份**明写的"不做"清单**，问到了会照直说"本卡不载"，**不凭记忆补一套规则出来**：

- ❌ 吉凶判等（「这一卦大吉还是凶？」——不判，吉凶在《易》里是「生乎动」的后果提示）
- ❌ 梅花易数的体用（十翼之外的推演规则库，本卡不走）
- ❌ 生辰八字、命运走势 → 转 [`bazi-paipan`](../bazi-paipan/) / [`geju-yunshi`](../geju-yunshi/)
- ❌ 算彩票、断疾病、断姻缘
- ❌ 把爻辞当签文直接照搬（爻辞本身就反对「为典要」）

> 这一条值得单独说：**别的工具把"什么都能答"当卖点，这张卡把"什么不答"写进了卡里**，
> 而且被质检验证过——它的「边缘诚实度」是满分。

跑过**独立交叉复核**（独立答题 Agent + 2 个互相独立的评分 Agent）：

| 总分 | 等级 | 两个评分者 | 边缘诚实度 |
|---|---|---|---|
| **96 / 100** | **A** | 97 / 97（分差 0） | **20 / 20** |

被问到**梅花易数起卦规则**、被要求**把「元亨利贞」换算成吉凶等级**时，它都明确声明
「超出卡片范围」并拒绝编造——**边缘诚实度满分**。

> ⚠️ 照实说一句：两个评分者给出的是**完全相同的总分**。按工具口径那只是
> 「请确认独立评分」的提醒，**不构成两次独立证实**。
