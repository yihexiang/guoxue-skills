# geju-yunshi · 八字格局与运势解读

[← 返回技能包首页](../../README.md) · [安装](../../README.md#安装)

> ### 盘已经排好了，然后呢？
> 这张卡回答：**这个八字整体是什么格局、日主强弱倾向如何、每一步大运传统上一般关联什么。**

一句话：它是 [`bazi-paipan`](../bazi-paipan/) 的**下半场**——盘是客观的，读法是传统的。
所以这张卡全程只说「**传统上一般关联**」，**不下断言、不给结论、不预测事件**。

---

## 🎯 它是干什么的

拿到一张已经排好的盘，它会按传统框架给你**四层可复核的描述**：

| 层 | 看什么 | 关键做法 |
|---|---|---|
| **日主强弱** | 得令 / 得地 / 得生扶 | 三要素逐条摆出来，结论只写「**倾向**」——不断绝对强弱 |
| **取格** | 月令本气 vs 透干 | **先声明用哪一派口径**，两派结论不同就如实说不同 |
| **五行与十神** | 生克制化、十神组合 | 落到具体干支上，不空谈「五行平衡」 |
| **大运** | 每步干支相对日主喜忌 | 一律表述为「传统上一般关联」，不是「你明年会……」 |

**谁适合用**：已经会排盘、但不知道「然后怎么看」的人；读过一堆命理文章但分不清
「哪句是原文、哪句是后人加料」的人；想验证某个解读到底有没有文本依据的人。

## ⚡ 怎么用

先把盘排出来（本卡不自己排盘），再把四柱交给它：

```bash
# 1) 排盘（上一张卡负责）
python3 skills/bazi-paipan/scripts/paipan.py "1990-05-15 14:30" --gender 乾

# 2) 然后直接问（Agent 会激活本卡）
> 庚午 辛巳 庚辰 癸未 这个盘，什么格局？日主强还是弱？下一步大运怎么看？
```

它会按卡内规定的**四层结构**回答（下面是结构示意，不是某次实跑的逐字输出——
本卡没有引擎，读法由 Agent 按卡执行）：

```
日主强弱：得令 / 得地 / 得生扶 三要素逐条列出
          → 结论只写「倾向…」，并指明哪一条是决定性的
取格：    月令本气派 vs 透干派 → 先声明用哪一派；
          两派结论不同就如实说不同，不取「看起来更像」的那个
五行十神：落到具体干支上，不空谈「五行平衡」
大运：    每步干支相对日主「补什么／泄什么」＋「传统上一般关联什么」
```

---

## 🚧 它明确不做的事（这是设计，不是缺陷）

- ❌ **不预测具体事件**：不问「哪年发财」「会不会离婚」「能不能升职」。
- ❌ **不给吉凶定论、不给人生建议**：问「该不该辞职」，它只会告诉你能说的那部分。
- ❌ **不判绝对强弱**：传统上本就门户有别，它只给「倾向」并声明口径。
- ❌ **不做跨体系换算**：比如「用大五人格量表换算日主强弱」——两套体系没有换算关系，它会直接说超出范围。
- ❌ **不自己排盘**：盘由 [`bazi-paipan`](../bazi-paipan/) 负责（本卡依赖它的引擎）。

> 为什么把边界划这么死：命理最容易出事的地方，是从「描述」滑向「断言」。
> 这张卡把「传统上一般关联」当成语法的一部分，**它不会替你做决定**。

## 📦 出厂质检

跑过**独立交叉复核**（独立答题 Agent + 2 个互相独立的评分 Agent）：

| 总分 | 等级 | 两个评分者 | 边缘诚实度 |
|---|---|---|---|
| **95 / 100** | **A** | 96 / 93（分差 3） | **20 / 20** |

边缘诚实度满分：被要求**预测 2027 年的升职与婚姻**、被要求**用大五人格换算日主强弱**时，
它都明确声明「超出卡片范围」并拒绝作答，**没有顺着编**。

报告：[`FIDELITY.json`](./FIDELITY.json)，可自行复算：
```bash
python3 <rulai-distill>/scripts/td.py gate skills/geju-yunshi/FIDELITY.json --min B
```
