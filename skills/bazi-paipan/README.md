# bazi-paipan · 八字四柱排盘

[← 返回技能包首页](../../README.md) · [安装](../../README.md#安装)

> ### 把「某年某月某日某时」变成一张**可交叉验证**的盘。
> 不做预测，不算吉凶——**只负责把盘排准，并把盘里每一项讲清楚**。

一句话：这是这套技能包里唯一一件**有客观对错**的事。四柱干支、藏干、十神、纳音、空亡、
起运与大运，全部由**零依赖的确定性引擎**算出，并和一部天文历算库对拍过 17 万次。

---

## 🎯 它是干什么的

| 能算 | 能解释 |
|---|---|
| 四柱干支（年/月/日/时）· 日主 | 藏干怎么来的、通根透出是什么意思 |
| 藏干与十神（对日主）· 纳音 · 空亡 | 十神各自代表什么、为什么以日干为原点 |
| 起运岁数 · 八步大运 · 顺逆 | 「阳年男顺排、阴年男逆排」到底怎么判 |
| 神煞（天乙贵人等） | 神煞在传统里是参考项还是硬判据 |

**谁适合用**：想知道自己八字排法对不对的人；看到「藏干」「十神」这些词没处查的人；
想核对别的软件排出不同结果时**到底哪个对**的人。

```
--- 推算轨迹 ---
· 年柱：庚午（立春 后，交节时刻 1990-02-04 10:14）
· 月柱：辛巳  月支按「节」定界，在立夏之后（交节 1990-05-06 02:35）
```

还有两个**流派口径开关**（不藏默认值，摆在命令行上）：
`--midnight {子初换日,子正换日}` 与 `--qiyun {月,日,不取整}`。

## 🔬 它凭什么可信：**173,426 次比对，差异 0**

排盘不是古籍解读，是**历算**——所以它可以被客观检验。本技能自带的零依赖引擎，
与天文历算库 [`lunar-python`](https://pypi.org/project/lunar-python/)（6tail，精度到秒）逐项对拍：

| 比对项 | 样本数 | 差异 |
|---|---|---|
| 日柱（1900–2100 **逐日**） | 73,414 | **0** |
| 四柱（每月 15 日 × 12 时辰中点） | 28,944 | **0** |
| 节气边界（每 5 年 × 24 节气 ±1 天 × 24 整点） | 70,848 | **0** |
| 大运干支序列 / 顺逆全组合 | 220 | **0** |
| **合计** | **173,426** | **0** |

复跑方式见 [`VERIFY.md`](./VERIFY.md)。引擎另有 **41 项自检**：

```bash
python3 skills/bazi-paipan/tests/test_engine.py     # 41 项全绿
```

**纯本地、零依赖、不联网、不调任何 API。**

## 🚧 它明确不做的事（这是设计，不是缺陷）

- ❌ **不预测个人具体事件**：不问「今年能不能升职」「什么时候结婚」——一律拒答。
- ❌ **不给吉凶定论**，不提供人生建议。
- ❌ **不做真太阳时校正**（这属流派口径分歧，且需要经度数据；本卡未内置）。
- ❌ **不判格局**：身强身弱、取格属 [`geju-yunshi`](../geju-yunshi/) 的职责。

> 为什么把「不做」写这么显眼：一个排盘工具最危险的时候，是它开始对**自己算不出的东西**开口。
> 把边界划死，你才能放心用它算得出的那部分。

## 📦 出厂质检

本卡跑过**独立交叉复核**（独立答题 Agent + 2 个互相独立的评分 Agent，分差门禁 >10 拒绝放行）：

| 总分 | 等级 | 两个评分者 | 边缘诚实度 |
|---|---|---|---|
| **93 / 100** | **A** | 92 / 93（分差 1） | **20 / 20** |

「边缘诚实度」是唯一能抓出「编造」的一维——它满分，意味着被问到**化气格的判法**、
**真太阳时的换算公式**这类素材外问题时，它会明确说「这超出卡片范围」，而不是顺着编一套出来。

报告：[`FIDELITY.json`](./FIDELITY.json)，可自行复算：
```bash
python3 <rulai-distill>/scripts/td.py gate skills/bazi-paipan/FIDELITY.json --min B
```
