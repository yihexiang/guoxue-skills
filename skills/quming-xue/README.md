# quming-xue · 取名学（依八字喜用神的综核取名）

[← 返回技能包首页](../../README.md) · [安装](../../README.md#安装)

> ### 不「缺啥补啥」，也不「数吉就赢」。
> 先定**八字喜用神**（补什么），再用**五格/三才/生肖/音律**做体检（怎么补得好看），
> 每个候选名都给一张**可复核的体检表**。

一句话：它把取名从「玄学推销」变成**因子分层 + 可复算的体检**——
哪一项是主驱动、哪一项只是参考，白纸黑字写在卡里。

---

## 🎯 它是干什么的

四步流程，每步都有明确输入输出：

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 取八字喜用神（经 [`bazi-paipan`](../bazi-paipan/) 排盘 + [`geju-yunshi`](../geju-yunshi/) 定喜用） | 喜用五行列表 + 日主强弱倾向 |
| 2 | 按喜用**海选候选字**（字形五行命中、字义端正、读音佳） | 每行 8–15 个候选字 |
| 3 | 组合成名 → 跑引擎**体检** | 五格 / 三才 / 生肖宜忌 / 喜用补字 / 平仄 一张表 |
| 4 | 权衡定稿（**保喜用神优先**） | 3–5 个推荐名 + 每个一句「为什么」 |

**谁适合用**：要给孩子取名、想要「既补命局又好看」的家长；
已有名字想做个**姓名学体检**的人；以及——**想知道"缺啥补啥"到底错在哪**的人。

## ⚡ 三十秒试一下（姓名体检）

```bash
# 在仓库根目录执行
python3 skills/quming-xue/scripts/wuge.py 李 昱坤 \
  --strokes 7,9,8 --zodiac 马 --xiyong 火,土 --tones 3,4,1
```

真实输出（逐字复制，未加工）：

```
姓名：李昱坤
笔画：[7, 9, 8]
五格：{'天格': 8, '人格': 16, '地格': 17, '外格': 9, '总格': 24}
三才：{'天格五行': '金', '人格五行': '土', '地格五行': '金', '等级': '吉', '说明': '无冲克'}
  天格8（吉）
  人格16（吉·首领/财富/女德/双妻/温和）
  地格17（半吉·刚情）
  外格9（凶）
  总格24（吉·财富/女德/温和）
生肖宜忌：{'生肖': '马', '宜用字': [('坤', '土')], '忌用字': [('昱', '日')]}
喜用补字：{'昱': '火', '坤': '土'}  未补：[]
平仄：{'平仄序列': '仄仄平', '提示': []}
```

### 注意这个例子里的「冲突」——它正是这张卡的重点

「昱」既命中**喜用（火）**，又落在**生肖忌用（日）**里。引擎不替你抹平，
它把两件事都摆出来；而卡里写死了权衡顺序：

> **喜用神为体、其余为用**；生肖是**参考**，不凌驾八字（`src-02 §0`）。
> 三才「大凶」也不是判决，是五行生克提示，禁止据单一点下死结论。

**这就是它和"输入姓名→告诉你大吉"的工具有本质区别的地方**：它暴露矛盾，然后告诉你按传统该听谁的。

## 🚧 它明确不做的事（这是设计，不是缺陷）

- ❌ **不做运势预测**：不说「这个名字决定孩子一生命运」。
- ❌ **不给吉凶定论、不神化**：「五格全吉」不等于人生顺遂。
- ❌ **不认可「缺啥补啥」**：八字里偏弱的那一行**可能恰是忌神**，缺什么就补什么是本卡明确反对的误区。
- ❌ **不替生僻字编数据**：拿不准的字要求查《起名专用字典》（字典不在卡内）；
  问它某个生僻字的笔画五行，它会说**查不到**，而不是猜一个。

> 取名的风险不在算错数，而在**用一套数把话说满**。这张卡只做因子分层——
> 所以它给的每个数你都能自己复算。

## 📦 出厂质检

跑过**独立交叉复核**（独立答题 Agent + 2 个互相独立的评分 Agent）：

| 总分 | 等级 | 两个评分者 | 边缘诚实度 |
|---|---|---|---|
| **96 / 100** | **A** | 96 / 95（分差 1） | **20 / 20** |

边缘诚实度满分：被要求给出**生僻字的康熙笔画与五格**、被要求**断言名字决定一生命运**时，
它都明确声明「超出卡片范围／卡片明确不做」，**没有编一个数出来**。

报告：[`FIDELITY.json`](./FIDELITY.json)，可自行复算：
```bash
python3 <rulai-distill>/scripts/td.py gate skills/quming-xue/FIDELITY.json --min B
```

**一处如实标注的短板**：本卡的底稿是对权威姓名学文献的**结构化合成提取**，
一手原文占比 **0.30**（不是 1.0）。这个数字在它的质检报告里被记为扣分项，没有粉饰。
